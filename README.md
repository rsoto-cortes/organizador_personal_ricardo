## OBJETIVO

El objetivo principal de este proyecto es aplicar de forma integra el flujo de preparacion, versionamiento y colaboracion de un proyecto.

## TECNOLOGIAS UTILIZADAS
Las tecnologias que se utilizaron para creacion de este proyecto son:VS Code, Git, GitHub.

## PASOS DE INSTALACION
1. Realizar un fork del proyecto Para tenerlo guardado en la nube

2. Clona este repositorio en tu equipocon el comando:
   git clone "URL del repositorio guardado en tu cuenta al realizar el fork"

3. Abre la carpeta del proyecto en VS Code.

4. Crea un entorno virtual para el proyecto:
   python -m venv .venv

5. Activa el entorno virtual en Windows PowerShell:
   .\.venv\Scripts\Activate.ps1

6. Instala las dependencias del proyecto:
   pip install -r requirements.txt

7. Ejecuta la aplicacion:
   python src/main.py

## DEPENDENCIAS
